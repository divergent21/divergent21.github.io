# Bayris — редизайн головної сторінки

Статична верстка (HTML + SCSS + мінімальний vanilla JS), без збірників і фреймворків.

## Структура

```
index.html          готова сторінка (посилається на css/main.css та js/main.js)
css/main.css         скомпільований CSS — саме цей файл підключений у index.html
scss/                вихідні SCSS-партіали за методологією БЕМ
  _variables.scss     кольори, шрифти, брейкпоінти
  _base.scss          ресет, типографіка, кнопки, секції
  _header.scss        хедер і десктопна навігація з підменю
  _mobile-menu.scss   повноекранне мобільне меню
  _hero.scss          hero-блок і стрічка категорій
  _products.scss      картки продукції
  _solutions.scss     блок «Рішення»
  _distributors.scss  блок «Як і де придбати»
  _news.scss          новини
  _about.scss         блок «Про компанію» з розгортанням
  _footer.scss        футер
  main.scss           точка входу — імпортує всі партіали
js/main.js            перемикання мобільного меню, акордеон підменю, "читати повністю"
```

## Робота з SCSS

Якщо потрібно перекомпілювати CSS після правок у `scss/`, скористайтеся будь-яким SCSS-компілятором, наприклад:

```
npx sass scss/main.scss css/main.css
```

`css/main.css` у цьому архіві вже зібраний і повністю відповідає `scss/`.

## Кольори бренду

- Терракота: #CF5C2E (основний акцент, кнопки, іконки)
- Терракота темна: #A8431C (посилання, hover)
- Терракота світла: #F2895A (акценти на темному тлі)
- Графіт: #2A2621 (текст, темні секції, футер)
- Крем: #F7F2EC / #EFE4D6 (фон)

## Шрифти

- Manrope (700/800) — заголовки, кнопки, акценти
- Inter (400–600) — основний текст

Підключені через Google Fonts у `<head>` — за потреби замініть на локальні файли шрифтів.
