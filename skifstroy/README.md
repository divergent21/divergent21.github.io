# Скиф Строй — редизайн главной страницы

Обычная вёрстка (HTML/CSS/JS), без сборщиков и фреймворков.
Классы — по методологии БЭМ. Стили написаны на SCSS (папка `scss/`),
в проект уже включён скомпилированный `css/style.css` — открывать
можно сразу, ничего собирать не нужно.

## Структура

```
index.html          — разметка главной страницы
css/style.css        — скомпилированный CSS (подключён в index.html)
js/main.js           — мобильное меню, дропдаун каталога, аккордеон, форма
images/              — плейсхолдеры (SVG) для фото — замените на реальные
scss/
  main.scss          — точка входа, все @import
  abstracts/
    _variables.scss  — цвета, шрифты, брейкпоинты, миксин .container
  base/
    _reset.scss
    _typography.scss
  components/
    _button.scss
    _logo.scss
  layout/
    _header.scss
    _mobile-nav.scss
    _hero.scss
    _catalog.scss
    _service.scss
    _about.scss
    _reviews.scss
    _steps.scss
    _delivery.scss
    _gallery.scss
    _contacts.scss
    _footer.scss
    _responsive.scss
```

## Пересборка CSS из SCSS

Если меняете стили — правьте файлы в `scss/`, затем скомпилируйте:

```
npm install -g sass
sass scss/main.scss css/style.css --style=expanded
```

(или через любой другой Sass-компилятор / сборщик вашего проекта —
структура партиалов стандартная и подойдёт для Webpack/Vite/Gulp).

## Цвета

- `--color-bg` `#FAF7F2` — тёплый белый фон
- `--color-ink` `#1D1B18` — основной текст
- `--color-accent` `#D9622B` — акцент (цвет кровельной черепицы)
- `--color-dark` `#20242A` — графитовые секции (услуги/шаги/галерея, футер)
- `--color-steel` `#5C7285` — резервный акцент

Точные фирменные цвета компании на сайте-источнике не определялись
визуально (доступен был только текст страницы) — палитра подобрана
под тематику (металл/кровля) и может быть скорректирована под логотип.

## Изображения

Все фото — SVG-плейсхолдеры с подписью, что должно быть на месте.
Замените файлы в `images/` на реальные фотографии, сохранив имена
и пропорции (см. `width`/`height` в `index.html`).

## Мобильное меню

Полноэкранная выезжающая панель (drawer) справа, тёмный фон,
аккордеон для каталога, кнопка консультации и телефоны внизу.
Открывается бургер-кнопкой в хедере (появляется < 900px).
